Erekir Neoplasm campaign map sources
====================================

The four initial campaign maps are unmodified Mindustry v160.7 Erekir maps reused as campaign map templates:
- contagion-outpost.msav <- onset.msav
- viscous-basin.msav <- basin.msav
- arterial-rift.msav <- siege.msav
- necrotic-citadel.msav <- origin.msav

Original maps: https://github.com/Anuken/Mindustry/tree/v160.7/core/assets/maps/erekir
The map files are provided as unchanged upstream campaign-map copies. The Java sector presets and Neoplasm tech-tree progression are Project Restoration additions.
